# MailVault quick guide for users

MailVault automatically saves email attachments (invoices, statements and so on) from shared mailboxes into the right
network folders. You don't need to do anything for that to happen; this guide shows how to **find** files and **check** what happened.

## Signing in

Open the MailVault address you were given and sign in. The first time, you'll be asked to choose your own password
(at least 10 characters, letters and numbers). You only see the mailboxes you were given access to.

## Finding a file

1. Go to **Download History**.
2. Filter by date, mailbox, rule, status, sender, subject or file name → **Apply**.
3. Click a row to see the details:
   - **Destination**: the full path. **Copy folder path** and paste it into File Explorer to open the folder.
   - **Save a copy**: downloads the file to your computer (if you have permission).
   - **View email**: shows the original email text.

## What the statuses mean

| Status | Meaning |
|---|---|
| Success | Saved to the folder shown |
| Skipped | Not saved on purpose: the reason is shown (e.g. identical file already saved, signature image, file type not selected) |
| Pending / Retrying | Will be saved shortly; MailVault tries again automatically |
| Waiting for folder | The network folder is temporarily unavailable; it continues by itself |
| Failed | Could not be saved; an administrator has been alerted |
| Awaiting manual download | This rule needs someone to confirm the download |

## Dashboard

Shows how many emails were checked and files saved, today and over time, per rule and per mailbox.
Use the mailbox selector (top right) to see one mailbox. Screens update by themselves (*Live* in the header).

## Exporting

**Download History → Export to Excel** exports everything that matches your current filters.

## Your settings

Click your name (top right):
- **My notification preferences**: get alerts by email, instantly or as a daily summary, and choose how important they must be.
- **Change password**.

## Something looks wrong?

Note the sender, subject and date of the email and tell your MailVault administrator. They can check exactly
why an email was or wasn't picked up.
